How it works

Every cycle is one pass through four steps. Each step appends a dated record to the run log; nothing happens silently.

  1. Health — GET /, /sitemap.xml, /robots.txt. Any non-200 fails the run and alerts the owner.
  2. Queue — every pending item in the content queue is published through the site's own CMS API (title, description, content). No credentials configured? Items are marked skipped — never lost.
  3. IndexNow — pings Bing, Yandex, Seznam and Naver for the homepage and sitemap when a key is configured.
  4. Status — regenerates the status page and JSON snapshot from the run log.

Why it can be left alone

  • Runs on GitHub-hosted runners — no server, no machine to keep alive, survives restarts by design.
  • The bot commits its own records back to the repository (message contains [skip ci], so it never re-triggers deploys).
  • Failures fail the workflow — GitHub emails the repo owner; a daily supervision check adds a second alerting layer.

What it does not do

  • No ranking guarantees. No tool can promise top-3 on Google.co.uk. The bot does the work; search engines decide.
  • No rule-breaking. It acts only on sites it is authorised for, within their terms of service, without bypassing authentication or rate limits.
  • No third-party scanning. It operates on noxptide.co.uk and the accounts the owner provides — nothing else.
  • No exposed secrets. Credentials live only in GitHub Actions secrets and are never written to logs, files or this page.

For operators

Everything needed to run, pause, configure and recover the system is in the runbook. The five items below are the only operator actions — the assistant cannot set secrets.

  1. Add secrets RAILWAY_TOKEN + RAILWAY_SERVICE_ID → deploys activate on every push to main.
  2. Add SEO_EDITOR_EMAIL + SEO_EDITOR_PASSWORD → queued content publishes live.
  3. Add INDEXNOW_KEY and host <key>.txt on the site → search-engine pings fire each cycle.
  4. Configure the Railway MySQL backup and test one restore.
  5. Trigger a cycle any time: repo → Actions → SEO Master Autopilot → Run workflow.
